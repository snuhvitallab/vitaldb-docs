> **Note:** This connection uses a custom **9-pin serial cable with pin 4 removed**. Some monitor configurations require a **GE Multi I/O adapter** to provide the RS-232 connector.

| Cable | Adapter | Port | VR Device Name |
|---|---|---|--- |
| Custom 9-pin serial cable with pin 4 removed | GE Multi I/O adapter if required; confirm the serial adapter for the cable used | 9-pin RS-232 connector | `Bx50` |

## Connection Requirements

- If the monitor has no accessible 9-pin RS-232 connector, confirm the compatible **Multi I/O adapter** with GE.
- Use the custom cable specified for this connection. Confirm its pin assignment and connector genders with the cable supplier.
- The null modem requirement is not consistent across the available guides. Confirm the complete cable configuration before adding a **null modem adapter (F/F)**.

## Connection Steps

1. Connect the custom serial cable to the monitor's **9-pin RS-232 connector** or the connector on its Multi I/O adapter.

## Device Configuration

No changes to the monitor settings are required for the connection described here.

## Vital Recorder Setup

- Add the device as **`Bx50`** and select the PC serial port used for the connection.
- Default waveforms are `ECG1`, `PLETH`, `IABP1`, `CO2`, and `AWP`. Use `IABP1` for invasive arterial pressure.
- For additional waveforms, see [S5 / Datex Device Settings](../../../Configuration_Guide.md#s5--datex-device-settings-ge-solar--bx50--b1x5m--canvas).
